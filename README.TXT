These folders with software were copied from Sanne van der Wal's home directory on a TU/e Linux workstation.

They contain the following:

folder toolbox: one of the releases of the BSO toolbox at that time on GitHub, including the files modified or added by Sanne (see her MSc-thesis)

folder sanne_code: files used to carry out the simulations in the MSc thesis Table 4, 5, and 6.

folder scdp_space_source: files used to do the simulations in the MSc thesis Figure 17.

folder code_used_for_publication/Tying_method: files used to run and obtain results of the Tying method for the paper: 
    Ezendam, T., van der, Hofmeyer, H., van der Wal, S., Perevendieva K.G., and Emmerich, M. T. M. 
    "Handling Complex Building Geometries for Disciplinary Processing in Conceptual Building Design 
    Simulation and Optimization". In: Computing in Civil Engineering (2026). DOI: 10.1061/JCCEE5.CPENG-6922 
    In this folder, there is a readme with further describtion

For instructions on how to install this directory is referred to the readme file: /MSc_2022_Van_der_Wal/toolbox/readme.md
