# README MSc_2022_Van_der_Wal

## What is this repository for?

These folders profide the code of the BSO toolbox including the Tying method.

The origonal software were copied from Sanne van der Wal's home directory on a TU/e Linux workstation. Containing both the origonal BSO toolbox version and the extensions Sanne van der Wal made to allow for the Tying method. Later on, the main code for the following publication was added to this repository: 

Ezendam, T., Hofmeyer, H., van der Wal, S., Perevendieva K.G., and Emmerich, M. T. M. "Handling Complex Building Geometries for Disciplinary Processing in Conceptual Building Design Simulation and Optimization". In: Computing in Civil Engineering (2026). DOI: 10.1061/JCCEE5.CPENG-6922

This repository contains all the code and data utilized for the Tying method for the above mentioned publication. In this publication, two other methods are introduced as well for a reference is specified in this publication to the code and data of the other two methods.

## Content repository

The repository contain the following:

folder code_used_for_publication: All the code and data utilized for the Tying method for the above mentioned publication. Please read the README in that folder for further specifications.
folder toolbox: one of the releases of the BSO toolbox at that time on GitHub, including the files modified or added by Sanne (see her MSc-thesis)
folder sanne_code: files used to carry out the simulations in the MSc thesis Table 4, 5, and 6.
folder scdp_space_source: files used to do the simulations in the MSc thesis Figure 17.
